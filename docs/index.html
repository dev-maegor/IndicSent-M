Multimodal NLP research

What does this meme really say?

IndicSent-M studies sentiment in Hinglish and English memes by combining the words on the image with the image itself.

Create a Gradio Space Explore the code

One meme, two signals

Read the text

EasyOCR extracts meme text, with an optional manual override for Hinglish or English.

Read the image

A Vision Transformer evaluates visual content that can change the meaning of the words.

Compare the signals

MuRIL and ViT predictions are fused, with token attribution and image attention for inspection.
